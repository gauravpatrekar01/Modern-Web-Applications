# Modern Web Applications

A collection of modern web development laboratory implementations built using **HTML, CSS, and JavaScript**. This repository demonstrates fundamental concepts of client-side web development through progressively structured practical exercises.

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* JavaScript Event Listeners
* Client-Side Programming

## Repository Structure

```text
Modern-Web-Applications/
│
├── Lab01/
├── Lab02/
├── Lab03/
├── Lab04/
├── Lab05/
└── README.md
```

## Labs

### Lab 01

Introduction to modern web application development and fundamental frontend concepts.

### Lab 02

Practical implementation of web development concepts using HTML, CSS, and JavaScript.

### Lab 03 — Basic Calculator

A functional calculator application developed using **HTML, CSS, and JavaScript**.

**Features:**

* Arithmetic operations
* Interactive user input
* JavaScript event listeners
* Client-side calculation logic
* Basic error handling

### Lab 04

Implementation of additional web application concepts using client-side technologies.

### Lab 05

Further practical implementation of modern web development concepts.

## Learning Objectives

This repository focuses on practical understanding of:

* Building structured web pages using HTML
* Styling interfaces with CSS
* Adding interactivity using JavaScript
* Handling user events
* Manipulating DOM elements
* Implementing client-side application logic
* Developing functional browser-based applications

## Getting Started

Clone the repository:

```bash
git clone https://github.com/gauravpatrekar01/Modern-Web-Applications.git
```

Navigate to the project:

```bash
cd Modern-Web-Applications
```

Open the required lab folder and launch the HTML file in a web browser.

For projects using Live Server, open the corresponding HTML file through **VS Code Live Server**.

## Purpose

This repository serves as a practical collection of **Modern Web Applications** coursework and demonstrates the implementation of core frontend development concepts through hands-on projects.
